## Working rules for this project
- No phase is implemented until the previous one is explicitly approved.
- Every backend module must have a visible, demonstrable UI state before it counts as done.
- No cyberpunk/neon defaults — visual direction is chosen deliberately, not by default.
- LLM usage is pluggable and never required for the app to run or demo.
