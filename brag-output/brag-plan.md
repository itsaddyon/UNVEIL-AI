# Brag Plan: UNVEIL AI (Extended 1-Minute Explainer)

## What is this app?
An investigator-facing platform that turns fragmented, synthetic dark-web intelligence into an explainable, evidence-backed map of probable threat-actor identities using graph analysis and probabilistic math.

## The angle
A comprehensive, cinematic explainer that breaks down the problem, the tech stack, the methodology (Noisy-OR), and the core features (Graph, Timeline, Attribution) for both technical and non-technical audiences.

## Hook (first 0-8 seconds)
"THE DARK WEB IS CHAOS." -> "UNVEIL AI BRINGS THE MATH."

## The Mission (8-16 seconds)
Explaining the goal: De-anonymizing threat actors using evidence-backed identity linking, not guesswork.

## The Tech Stack (16-24 seconds)
- **Frontend:** React, TypeScript, Vite, Cytoscape.js
- **Backend:** Python, FastAPI, NetworkX, SQLite
- **Engine:** Deterministic State Machine & Probabilistic Fusion

## Feature 1: Investigation Workspace (24-36 seconds)
Showcasing the Case Management system. "Track every investigation in isolated environments." Example: Operation Nightfall.

## Feature 2: Graph & Attribution (36-48 seconds)
Showcasing the Cytoscape graph connecting aliases (ShadowFox, DarkWolf). Explaining the 87% Noisy-OR Fusion score based on PGP matches and infrastructure correlation.

## Feature 3: Timeline Analysis (48-56 seconds)
Showcasing the temporal alignment of events. Tracking alias migrations and correlated neighbors over time.

## Outro (56-60 seconds)
"UNVEIL AI." -> "De-anonymize the dark web."
